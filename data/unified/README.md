# UNIFIED data corpus (per-prompt CSVs)

This directory holds the per-prompt UNIFIED CSVs produced by Hydra's
unifier (`analysis/unifier/data_unifier_parallel.py`), packaged as a split tarball
because the combined corpus exceeds GitHub's 100 MB per-file push limit.

## Contents

- `hydra_unified.tar.xz.part00` — 90 MB
- `hydra_unified.tar.xz.part01` — 20 MB

Together they reassemble to `hydra_unified.tar.xz` (~115 MB), which
extracts to **286 CSV files, ~430 MB**, covering:

- the 190-configuration main IFEval corpus (3 platforms × 2 backends ×
  5 precisions × 13 models, minus 5 Xavier llama.cpp F16 failures), and
- the S1 (input-length) and S2 (output-length) sensitivity sweeps on
  Orin and Thor.

Each `UNIFIED_*.csv` has one row per prompt with the 25 base timing
columns plus per-phase `tegrastats`/NVML telemetry aggregates
(`*_prompt_mean`, `*_prefill_mean`, `*_decode_mean` and the matching
`_std`).

## How to reassemble and extract

```
cd data/unified
cat hydra_unified.tar.xz.part* > hydra_unified.tar.xz
tar -xJf hydra_unified.tar.xz -C /path/to/extract/
```

The analysis code expects the extracted layout to mirror the original
`/media/amir/data/hydra-results/` tree (subdirs per platform, plus
`results_sensitivity/`).

## Regenerating from raw INFO/TGS

The raw INFO + TGS inputs (~43 GB) are not in this repo. They can be
regenerated by re-running the inference scripts:

```
bash scripts/run_hf_experiments.sh
bash scripts/run_llamacpp_experiments.sh

bash scripts/run_unifiers.sh             /media/amir/data/hydra-results
bash scripts/run_unifiers_sensitivity.sh /media/amir/data/hydra-results
```

The unifier is idempotent (skips configs that already have a
`UNIFIED_*.csv`).
